# Pictograma ANPC SAL

`sal-pictograma.png` este fișierul oficial ANPC, descărcat nemodificat de la
https://www.anpc.ro/download/sal/SAL-PICTOGRAMA.png (pagina https://www.anpc.ro/sal),
pe 7 octombrie 2026.

Obligația: Ordinul ANPC nr. 449/2022, modificat prin Ordinul nr. 270/2026, după
desființarea platformei europene SOL (20 iulie 2025, Regulamentul UE 2024/3228).
Site-urile care fac publicitate unor servicii pentru consumatori afișează
pictograma SAL cu link extern către platforma ANPC: https://reclamatiisal.anpc.ro.
Pictograma SOL nu mai este necesară.

Apare în subsolul fiecărei pagini (src/components/Footer.tsx), deci și pe prima
pagină. Dacă ANPC publică o pictogramă nouă, se înlocuiește fișierul de aici.
